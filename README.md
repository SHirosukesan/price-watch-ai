# Price Watch シンプルshiro_AI

Sony・Bose のヘッドホン／イヤホン 4機種の価格を、Amazon・楽天市場・Yahoo!ショッピングで見張る自分専用アプリです。
スマホ（Android・iPhone）と PC（Windows・Mac）のブラウザで使え、ホーム画面に追加するとアプリのように起動できます（PWA）。

## できること（第1段階）

- 4機種の商品画像と最安値（楽天・Yahoo!の実価格）、販売ページへのリンク
- Amazon は「Keepa」（無料の価格推移サイト）と Amazon へのボタン
- 目標価格を自由に変更・保存（端末ごと）
- 目標価格以下になったら通知（アプリを開いている間）
- 値下がりをスマホへ通知（任意・ntfy を使う場合。アプリを閉じていても届く）
- 大型セール（Amazon プライム感謝祭）のカウントダウンを常に表示
- 取得時刻・取得状態の表示、初心者向けの「動作チェック」

| 監視する商品 | 初期の目標価格 |
|---|---|
| Sony WH-1000XM6 | 47,000円 |
| Sony WF-1000XM6 | 33,000円 |
| Bose QuietComfort Ultra Headphones 第2世代 | 42,000円 |
| Bose QuietComfort Ultra Earbuds 第2世代 | 28,000円 |

## しくみ（ざっくり）

```
GitHub Actions（1時間ごとに自動実行）
   │ Keepa API（Amazon）・楽天API・Yahoo!APIで価格と画像を取得 → data/prices.json を作る
   ▼
GitHub Pages（無料の公開場所）
   │ アプリと価格データを公開
   ▼
スマホ・PC のブラウザでアプリを開く → 目標価格と比べて表示・通知
```

- **実価格とサンプル価格**：キーを登録する前は灰色の「サンプル」表示になります。実価格になると緑の「実価格」ラベルが付きます。
- **Amazon（無料の方法）**：Amazon公式の価格API（Creators API）は「直近30日に10件以上のアフィリエイト売上」が条件で個人では使えず、規約内で無料かつ自動で数字を取る方法はありません。そこで次の2つで補います。
  - アプリの「Keepa」ボタン：Amazon の現在価格と値動きのグラフを無料で確認
  - Keepa の無料「トラッキング」：希望価格を登録すると、Amazon で下がったときにメールが届く（下の手順）
- （任意・有料）Keepa の API キー（月額 約49ユーロ）を `KEEPA_API_KEY` に登録すると、Amazon の価格もアプリの一覧に自動で並びます。
- **商品画像**：各サイトのAPIが返す商品画像を表示します（キー登録前は灰色の枠）。
- **スクレイピングはしません**。楽天・Yahoo! の公式APIだけを使います。
- **キーはコードに書きません**。GitHub の「Secrets」（鍵の保管庫）に保存します。

## 費用

すべて無料です。有料の Keepa API を使う場合だけ費用がかかります（GitHub 公開リポジトリ・GitHub Pages・GitHub Actions・楽天API・Yahoo!API・ntfy）。

Keepa API は最安プランで月額 約49ユーロ（約8,000〜9,000円。正確な金額は Keepa の API 画面で確認）。月単位で解約できるので、セールのある月だけ契約する使い方もできます。

## はじめての設定（全体の流れ）

細かい操作は Claude が1ステップずつ案内します。ここは全体像です。

1. GitHub のアカウントを作る
2. リポジトリ（ファイル置き場）`SHirosukesan/price-watch-ai` を **Private（非公開）** で作る（作成済み）
3. このフォルダの中身をすべてアップロードする（`.github` フォルダも含む）
4. アプリの公開先を決める（※無料プランの非公開リポジトリでは GitHub Pages が使えないため。決まり次第ここを更新します）
5. Actions タブで「価格を取得してアプリを更新」を実行 → アプリのURLが開ければ成功（この時点ではサンプル価格）
6. 楽天ウェブサービスでアプリ登録し、**アプリID** と **アクセスキー** を取得（WebサイトURL にはアプリのURLを登録）
7. Yahoo!デベロッパーネットワークで **Client ID** を取得
8. GitHub の Settings → Secrets and variables → Actions に、次の名前で登録

   | 名前 | 中身 |
   |---|---|
   | `RAKUTEN_APP_ID` | 楽天のアプリID |
   | `RAKUTEN_ACCESS_KEY` | 楽天のアクセスキー |
   | `YAHOO_APP_ID` | Yahoo! の Client ID |
   | `KEEPA_API_KEY`（任意・有料） | Keepa の APIキー（Amazon価格用） |
   | `NTFY_TOPIC`（任意） | ntfy のトピック名（推測されにくい長い名前に） |

9. もう一度 Actions で実行 → 「実価格」表示に変われば完成
10. スマホの Chrome でアプリを開き、メニュー「︙」→「ホーム画面に追加」。設定画面で「通知を許可する」

## Amazon の値下がりをメールで受け取る（無料・最初に1回だけ）

1. https://keepa.com を開き、右上からアカウントを無料登録（地域は「co.jp」）
2. アプリの商品カードにある「Keepa」ボタンで商品を開く
3. 「商品のトラッキング」→「Amazon」と「新品」の欄に目標価格を入力 →「トラッキング開始」
4. 4商品分くり返す（1商品1分ほど）

## アプリを閉じていても通知を受けたい（任意：ntfy）

1. スマホに無料アプリ「ntfy」をインストール
2. ntfy で「+」→ トピック名（例：`shiro-ai-7f3k9q2m`）を入力して購読
3. 同じトピック名を GitHub の Secrets に `NTFY_TOPIC` として登録

前回の取得より最安値が下がると通知が届きます。トピック名を知っている人は誰でも通知を読めるため、推測されにくい名前にしてください（個人情報は送っていません）。

## 変更の保存と復元（Git の履歴）

- Claude がファイルを変えるたびに、GitHub に「いつ・何を変えたか」の記録（コミット）が残ります。
- 履歴を見る：GitHub の price-watch-ai を開き、ファイル一覧の上にある「◯ Commits」をクリック。
- 元に戻したいとき：Claude に「◯月◯日の版に戻して」「さっきの変更を取り消して」と頼めば、記録から戻せます。古い記録は消えないので、戻したあとでも再び戻せます。

## キーやパスワードを守るしくみ

- キーは GitHub の Secrets（鍵の保管庫）にだけ入れます。コードや README、チャットには書きません。
- `.gitignore` で `.env` などキーを書きがちなファイルは GitHub に送られない設定です。
- Secrets の中身は登録した本人も後から見られず、自動処理の記録（ログ）にも `***` と伏せ字で表示されます。

## 困ったとき

まずアプリの **設定 → 動作チェック** を押してください。結果ごとに直し方が表示されます。

| 症状 | よくある原因と対処 |
|---|---|
| ずっと「サンプル」のまま | Secrets の名前が違う／登録後に Actions を実行していない |
| 楽天：キーが違うか…URLと一致しません | 楽天のアプリ設定の「WebサイトURL」を `https://（ユーザー名）.github.io/` にする |
| 取得が2時間以上止まっている | Actions タブで赤い×の実行を開き、エラーを Claude に貼り付けて相談 |
| 価格が付属品やケースの値段になる | `data/products.json` の `minPrice` を上げる／`excludeWords` に言葉を足す |
| 通知が来ない | 設定 → 通知を許可。Android は「ホーム画面に追加」した方が安定します |

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（商品・セール・設定の3画面） |
| `style.css` | 見た目（色は先頭の `:root` で変更） |
| `app.js` | 画面の動き・目標価格の保存・通知・動作チェック |
| `sw.js` | オフライン対応と通知クリック（PWA） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `data/products.json` | 監視する商品と検索条件（商品の追加はここ） |
| `data/sales.json` | セール予定（追加・変更はここ） |
| `data/prices.json` | 取得した価格（自動で作られる。手で編集しない） |
| `scripts/fetch-prices.mjs` | Amazon(Keepa)・楽天・Yahoo! から価格と画像を取る処理 |
| `.github/workflows/update-prices.yml` | 1時間ごとの自動実行と公開の設定 |

## 注意

- 表示価格は取得時点のもので、ポイント・クーポン・送料の細かい条件は含みません。購入前に販売ページで必ず確認してください。
- GitHub の定期実行は混雑時に数分〜十数分遅れることがあります。
- 価格データの出典：Keepa ／ Supported by Rakuten Developers ／ Web Services by Yahoo! JAPAN
- Amazon の「他の出品者（新品）」はマーケットプレイスの最安値です。販売元・評価を販売ページで確認してください。
